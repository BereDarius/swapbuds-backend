# Release v0.5.0 - Likes & Comments

**Release Date:** November 2024
**Version:** 0.5.0
**Type:** Feature Release

## 🎯 Overview

This release adds user engagement features to the SWAPBUDS platform, enabling users to like items and leave comments for community interaction.

## ✨ New Features

### Likes Module

- **Like/Unlike Items**: Toggle likes with a single action
- **Likes Count**: View total likes for any item
- **Like Status**: Check if current user has liked an item
- **Like Users List**: See all users who liked an item (with avatars)
- **Duplicate Prevention**: Unique constraint prevents multiple likes from same user

### Comments Module

- **Create Comments**: Add comments to items (max 1000 characters)
- **View Comments**: Browse all comments for an item
- **Edit Comments**: Modify your own comments
- **Delete Comments**: Remove your own comments
- **Comment Count**: Get total comments for items
- **User Information**: Comments include username, avatar, and timestamps

## 🔌 API Endpoints

Ten new REST endpoints for engagement features:

**Likes Endpoints:**

| Method | Endpoint                         | Description         | Authorization      |
| ------ | -------------------------------- | ------------------- | ------------------ |
| POST   | `/api/items/:itemId/like`        | Like an item        | Authenticated user |
| DELETE | `/api/items/:itemId/like`        | Unlike an item      | Authenticated user |
| GET    | `/api/items/:itemId/likes/count` | Get likes count     | Authenticated user |
| GET    | `/api/items/:itemId/likes/me`    | Check if user liked | Authenticated user |
| GET    | `/api/items/:itemId/likes/users` | Get users who liked | Authenticated user |

**Comments Endpoints:**

| Method | Endpoint                            | Description       | Authorization      |
| ------ | ----------------------------------- | ----------------- | ------------------ |
| POST   | `/api/items/:itemId/comments`       | Create comment    | Authenticated user |
| GET    | `/api/items/:itemId/comments`       | Get all comments  | Public             |
| PATCH  | `/api/items/comments/:commentId`    | Update comment    | Owner only         |
| DELETE | `/api/items/comments/:commentId`    | Delete comment    | Owner only         |
| GET    | `/api/items/:itemId/comments/count` | Get comment count | Public             |

## 🏗️ Technical Implementation

### New Modules

- **LikesModule**: Complete module with service and controller
- **CommentsModule**: Complete module with service and controller

### Likes Features

- Unique constraint on `userId + itemId` prevents duplicates
- Returns `409 Conflict` if already liked
- Validates item existence before creating like
- User aggregation for "who liked" queries

### Comments Features

- Full ownership validation for edit/delete operations
- Returns `403 Forbidden` for unauthorized modifications
- User info (username, avatarUrl) included in responses
- Ordered by creation date (newest first)
- Max length validation (1000 characters)

### Database

- Uses existing Prisma schema with proper relations and indexes
- Efficient queries with includes for user data

## 📝 Business Rules

### Likes

- ✅ Users can like any available item
- ✅ Cannot like the same item twice (unique constraint)
- ✅ Can unlike previously liked items
- ✅ Item must exist to be liked
- ✅ Like count updates automatically

### Comments

- ✅ Comments max length: 1000 characters
- ✅ Only comment owner can edit/delete
- ✅ Comments visible to all users
- ✅ Includes user information (username, avatar)
- ✅ Ordered by creation date (newest first)

## 🔄 Migration Notes

No database migrations required. Like and Comment models exist in initial schema.
