# Backend v1.3.0 - Legal Documents Database Integration

**Release Date:** November 29, 2025

## Overview

Major feature release adding database-driven legal document management with markdown support, enabling versioned Terms of Service, Privacy Policy, and Cookie Policy with bilingual content.

---

## 🎉 New Features

### Legal Documents System

- **Database-driven legal content**: Store legal documents in PostgreSQL with version management
- **Markdown support**: Legal documents stored as markdown for easy editing
- **Bilingual content**: Support for English and Romanian versions
- **Version management**: Track multiple versions with active/inactive states
- **Effective dates**: Documents include effective date tracking
- **Prisma seed script**: Automated seeding of legal documents from markdown files

### Legal Documents Directory Structure

- Created `/prisma/legal-documents/` directory for markdown files
- README with instructions for file naming and seed process
- Support for 6 markdown files (3 document types × 2 languages):
  - `terms-of-service.en.md` / `terms-of-service.ro.md`
  - `privacy-policy.en.md` / `privacy-policy.ro.md`
  - `cookie-policy.en.md` / `cookie-policy.ro.md`

### Database Schema

- `LegalDocument` model with type, version, content (bilingual), title, summary, effectiveAt, isActive
- Unique constraint on `type` + `version` combination
- Index on `type` + `isActive` for fast queries
- Proper Prisma seed configuration in `package.json`

---

## 🔧 Improvements

### Legal Service

- API endpoint returns language-specific content as `content` field
- Active document version retrieval by type
- Automatic deactivation of old versions when setting new active version
- Graceful handling of missing markdown files (placeholder content)

### Seed Script

- Idempotent seed operation (skips existing documents)
- Reads markdown files from `/prisma/legal-documents/`
- Creates placeholder content if files not found
- Version 1.0.0 initial documents with January 1, 2025 effective date
- Console logging for transparency during seed

---

## 🧪 Technical Details

### Database Changes

- Added `legal_documents` table via Prisma schema
- Enum: `LegalDocumentType` (TERMS_OF_SERVICE, PRIVACY_POLICY, COOKIE_POLICY, COMMUNITY_GUIDELINES)
- Text fields for markdown content storage
- Timestamp tracking (createdAt, updatedAt)

### API Response Format

```json
{
  "id": "cuid",
  "type": "TERMS_OF_SERVICE",
  "version": "1.0.0",
  "title": "Terms of Service",
  "content": "# Terms of Service\n\n...",
  "summary": "Initial version",
  "effectiveAt": "2025-01-01T00:00:00.000Z",
  "createdAt": "2025-11-29T...",
  "updatedAt": "2025-11-29T..."
}
```

### Configuration

- Prisma seed command: `ts-node prisma/seed.ts`
- Seed runs with: `yarn prisma db seed` or `npx prisma db seed`
- ts-node already included as dev dependency
