## 🎉 Release v0.3.0 - Cloudinary Integration

This release adds complete image upload functionality with Cloudinary integration, enabling users to upload images for their items.

### ✨ New Features

- **Image Upload API** - Complete Cloudinary integration for file uploads
  - Multiple file upload support (max 10 images per request)
  - Automatic image optimization and transformations
  - Smart image resizing (max 1200x1200, preserves aspect ratio)
  - Auto quality and format optimization
  - File type validation (JPEG, PNG, WebP, GIF)
  - File size validation (max 5MB per file)
  
- **Upload Service** - Comprehensive Cloudinary service
  - Upload single/multiple images
  - Delete images by public ID
  - Generate transformed image URLs
  - Configurable folder structure

- **Upload Module** - New NestJS module
  - JWT authentication required
  - Full Swagger/OpenAPI documentation
  - Proper error handling and validation

### 📊 New API Endpoint

- `POST /api/upload/images` - Upload multiple images (authenticated)
  - Requires: JWT Bearer token
  - Accepts: multipart/form-data with 'files' field
  - Returns: Array of image URLs and metadata

### 🔧 Configuration

New environment variables added:
- `CLOUDINARY_CLOUD_NAME` - Your Cloudinary cloud name
- `CLOUDINARY_API_KEY` - Your Cloudinary API key
- `CLOUDINARY_API_SECRET` - Your Cloudinary API secret

See `.env.example` for setup instructions.

### 📦 Dependencies

- `cloudinary@2.8.0` - Cloudinary SDK
- `multer@2.0.2` - File upload middleware
- `@types/multer@2.0.0` - TypeScript types
