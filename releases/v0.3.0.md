# Release v0.3.0 - Cloudinary Integration

**Release Date:** October 2024
**Version:** 0.3.0
**Type:** Feature Release

## 🎯 Overview

This release adds complete image upload functionality with Cloudinary integration, enabling users to upload and manage images for their items.

## ✨ New Features

### Image Upload API

- **Multiple File Upload**: Upload up to 10 images per request
- **Automatic Optimization**: Smart image resizing (max 1200x1200, preserves aspect ratio)
- **Format Optimization**: Auto quality and format selection for best performance
- **File Validation**: Type validation (JPEG, PNG, WebP, GIF) and size limits (max 5MB per file)

### Upload Service

- **Single/Multiple Uploads**: Flexible upload methods
- **Image Deletion**: Delete images by public ID
- **URL Generation**: Generate transformed image URLs on-demand
- **Folder Structure**: Configurable Cloudinary folder organization
- **Environment Separation**: Different folders for dev/staging/prod

### Upload Module

- JWT authentication required
- Full Swagger/OpenAPI documentation
- Comprehensive error handling and validation

## 🔌 API Endpoints

One new REST endpoint for image uploads:

| Method | Endpoint             | Description            | Authorization      |
| ------ | -------------------- | ---------------------- | ------------------ |
| POST   | `/api/upload/images` | Upload multiple images | Authenticated user |

**Request Format**: multipart/form-data with 'files' field
**Response**: Array of image URLs and metadata (public_id, secure_url, width, height)

## 🏗️ Technical Implementation

### New Modules

- **UploadModule**: NestJS module for file uploads
- **UploadService**: Cloudinary integration service
- **UploadController**: REST API endpoint with multer middleware

### Configuration

New environment variables:

- `CLOUDINARY_CLOUD_NAME`: Your Cloudinary cloud name
- `CLOUDINARY_API_KEY`: Your Cloudinary API key
- `CLOUDINARY_API_SECRET`: Your Cloudinary API secret

### Dependencies

- `cloudinary@2.8.0`: Cloudinary SDK for Node.js
- `multer@2.0.2`: File upload middleware
- `@types/multer@2.0.0`: TypeScript type definitions

## 📝 Business Rules

### File Upload

- ✅ Maximum 10 files per request
- ✅ Allowed formats: JPEG, PNG, WebP, GIF
- ✅ Maximum file size: 5MB per file
- ✅ Automatic image optimization and resizing
- ✅ Images stored in environment-specific folders (dev/stage/prod)

### Image Transformations

- ✅ Width/height limit: 1200x1200 pixels
- ✅ Crop mode: limit (maintains aspect ratio)
- ✅ Quality: auto (Cloudinary optimization)
- ✅ Format: auto (best format for client)

## 🔄 Migration Notes

No database migrations required. Update `.env` file with Cloudinary credentials.

## 🚀 Deployment

### Prerequisites

- Cloudinary account with API credentials
- Existing authentication system (JWT)

### Installation

```bash
# Pull latest code
git pull origin main

# Install dependencies
yarn install

# Update .env with Cloudinary credentials
cp .env.example .env
# Edit CLOUDINARY_* variables

# Build and start
yarn build
yarn start:prod
```

## 🔐 Security

- All endpoints require JWT authentication
- File type validation prevents malicious uploads
- File size limits prevent abuse
- Cloudinary API keys stored in environment variables
