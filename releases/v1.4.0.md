# Release v1.4.0 - Enhanced Testing & Seed System

**Release Date**: November 29, 2025
**Version**: 1.4.0
**Release Type**: Feature Release

## 🎯 Overview

This release significantly improves backend test coverage, introduces a comprehensive database seed system for local development and E2E testing, and adds new verification features including selfie verification capabilities. The focus is on developer experience, testing infrastructure, and enhanced user verification workflows.

## ✨ New Features

### Testing Infrastructure

- **Comprehensive Test Coverage**: Achieved 87.3% branch coverage (up from 83.55%) across 1,287 tests
- **Test Fixtures**: Created reusable test fixtures for comments, likes, messages, and other entities
- **Mock Services**: Enhanced mock implementations for all major services
- **Waitlist Testing**: Added full unit test coverage for waitlist controller and service

### Database Seed System

- **Modular Seed Architecture**: Split seed functionality into 8 specialized files for maintainability
- **Realistic Test Data**: 8 users (admin, moderator, support, 5 regular users), 14 items across categories, 5 trades with various statuses
- **Complete Data Graph**: Seeds include users, items, trades, engagement (likes/comments), reviews, notifications, support chats, legal documents, and user settings
- **Dependency-Ordered Execution**: Automatic resolution of entity dependencies during seeding
- **Production-Ready**: Suitable for both local development and E2E test scenarios

### Verification Enhancements

- **Selfie Verification**: Added selfie photo support for enhanced identity verification
- **Document Front/Back**: Support for uploading both sides of ID documents
- **Enhanced Security**: Improved document encryption and secure URL generation
- **Verified Guard**: New `@Verified()` decorator for protecting endpoints requiring verified users
- **Version History**: Track document and message changes for compliance and auditing

## 📝 Business Rules

### Seed System

- ✅ Seeds must run in dependency order: legal → users → settings → items → engagement → trades → reviews → notifications
- ✅ All passwords hashed with bcrypt (default: "password123" for testing)
- ✅ User roles distributed: 1 admin, 1 moderator, 1 support, 5 regular users
- ✅ Items span all categories and conditions for comprehensive testing
- ✅ Trades represent all lifecycle states (PENDING, ACCEPTED, COMPLETED, REJECTED)

### Verification System

- ✅ Selfie verification optional but recommended for higher trust score
- ✅ Document front is mandatory, back is optional (depends on document type)
- ✅ All uploaded documents encrypted at rest
- ✅ Secure URLs expire after configuration period
- ✅ Version history maintained for compliance (GDPR Article 15)

## 🔄 Migration Notes

To apply the new database migrations and seed data:

```bash
# Run migrations
yarn prisma migrate deploy

# Generate Prisma client
yarn prisma generate

# Seed database (optional - for development/testing)
yarn prisma db seed
```

## 🚀 Deployment

### Prerequisites

- Node.js 20+
- PostgreSQL database
- Redis instance (for caching)
- Environment variables configured

### Installation

```bash
# Pull latest code
git pull origin main

# Install dependencies
yarn install

# Run migrations
yarn prisma migrate deploy

# Generate Prisma client
yarn prisma generate

# Seed database (development only)
yarn prisma db seed

# Restart application
yarn start
```
