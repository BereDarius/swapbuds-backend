# Release v0.2.0 - Items Module

**Release Date:** October 2024
**Version:** 0.2.0
**Type:** Feature Release

## 🎯 Overview

This release introduces the complete Items module with full CRUD operations, category system, and comprehensive documentation updates.

## ✨ New Features

### Items CRUD API

- **Create Items**: Add new items with ownership validation
- **List Items**: Paginated item listing for browsing
- **Get Item Details**: View individual item information
- **Get User's Items**: Filter items by user
- **Update Items**: Modify your own items
- **Delete Items**: Remove your own items
- **Category System**: 8 predefined categories (ELECTRONICS, CLOTHING, BOOKS, TOYS, SPORTS, COLLECTIBLES, HOME, OTHER)
- **Condition Tracking**: 5 condition states (NEW, LIKE_NEW, GOOD, FAIR, POOR)
- **Image Support**: Multiple images per item (Cloudinary integration ready)
- **Ownership Validation**: Users can only modify their own items

## 🔌 API Endpoints

Six new REST endpoints for item management:

| Method | Endpoint                  | Description                | Authorization      |
| ------ | ------------------------- | -------------------------- | ------------------ |
| POST   | `/api/items`              | Create new item            | Authenticated user |
| GET    | `/api/items`              | List items with pagination | Public             |
| GET    | `/api/items/:id`          | Get item details           | Public             |
| GET    | `/api/items/user/:userId` | Get user's items           | Public             |
| PATCH  | `/api/items/:id`          | Update item                | Owner only         |
| DELETE | `/api/items/:id`          | Delete item                | Owner only         |

## 🏗️ Technical Implementation

### New Modules

- **ItemsModule**: Complete NestJS module with service, controller, and DTOs
- **ItemsService**: Business logic with ownership validation
- **ItemsController**: REST API endpoints with Swagger documentation

### DTOs

- `CreateItemDto`: Validation for item creation
- `UpdateItemDto`: Partial update validation
- Item response with user and image relations

### Database

- Item model with categories and conditions
- Relations: Item → User (owner), Item → ItemImage (multiple images)
- Indexes for efficient querying

## 📝 Business Rules

### Item Creation

- ✅ Must provide title, description, category, condition
- ✅ Automatic owner assignment from JWT token
- ✅ Optional location and image URLs
- ✅ Default status: AVAILABLE

### Item Updates

- ✅ Only the owner can update their items
- ✅ All fields optional for partial updates
- ✅ Cannot change ownership

### Item Deletion

- ✅ Only the owner can delete their items
- ✅ Cascading deletion of related images

## 🔄 Migration Notes

Initial implementation - no migration from previous version required.

## 🚀 Deployment

### Prerequisites

- PostgreSQL database
- Authentication system (JWT)
- Prisma client generated

### Installation

```bash
# Pull latest code
git pull origin main

# Install dependencies
yarn install

# Run migrations
yarn prisma migrate deploy

# Build and start
yarn build
yarn start
```
