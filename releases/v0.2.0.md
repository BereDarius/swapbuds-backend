## 🎉 Release v0.2.0

This release introduces the complete Items module with full CRUD operations and comprehensive documentation updates.

### ✨ Features

- **Items CRUD API** - Complete RESTful endpoints for item management
  - Create items with ownership validation
  - List all items with pagination support
  - Get items by user ID
  - Update items (owner only)
  - Delete items (owner only)
- **Category System** - 8 predefined categories (ELECTRONICS, CLOTHING, BOOKS, TOYS, SPORTS, COLLECTIBLES, HOME, OTHER)
- **Condition Tracking** - 5 condition states (NEW, LIKE_NEW, GOOD, FAIR, POOR)
- **Image Support** - Multiple images per item with Cloudinary integration ready
- **Swagger Documentation** - Interactive API docs with all endpoints documented
- **Ownership Validation** - Users can only modify their own items

### 🔧 Improvements

- **Path Aliases** - Updated to use `@/` prefix consistently with frontend
- **Documentation** - Comprehensive README with API examples, deployment guides, and troubleshooting
- **Package Metadata** - Updated package.json with proper description and author

### 📊 API Endpoints

- `POST /api/items` - Create item (authenticated)
- `GET /api/items` - List items with pagination (public)
- `GET /api/items/:id` - Get item details (public)
- `GET /api/items/user/:userId` - Get user's items (public)
- `PATCH /api/items/:id` - Update item (owner only)
- `DELETE /api/items/:id` - Delete item (owner only)
