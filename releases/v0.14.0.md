# Release v0.14.0 - User Settings & Preferences

**Release Date**: November, 2024
**Version**: 0.14.0
**Release Type**: Feature Release

## 🎯 Overview

Comprehensive user settings system with 30+ configurable options across profile, privacy, trade, notification, UI, search, accessibility, and marketing categories, giving users complete control over their SwapBuds experience.

## ✨ New Features

### User Settings System

- **Profile Settings**: Display email, location visibility, message permissions
- **Privacy Settings**: Profile visibility (PUBLIC/FRIENDS_ONLY/PRIVATE), trade history, reviews, statistics display
- **Trade Settings**: Auto-decline expired trades, counter-offer permissions, required trade messages
- **Notification Frequency**: Email digest (REALTIME/DAILY/WEEKLY/NEVER), Push digest (REALTIME/HOURLY/DAILY/NEVER)
- **UI Preferences**: Theme (LIGHT/DARK/AUTO), Language (EN/ES/FR/DE/PT), pagination, sorting, view mode
- **Search & Discovery**: Search history, similar items, personalized recommendations
- **Accessibility**: High contrast, large text, reduced motion, screen reader mode
- **Marketing**: Marketing emails, product updates, community newsletter
- **Advanced**: Two-factor authentication toggle, configurable session timeout

## 🔌 API Endpoints

### New Endpoints

| Method | Endpoint                       | Description                | Authorization |
| ------ | ------------------------------ | -------------------------- | ------------- |
| GET    | `/api/users/me/settings`       | Get current user settings  | JWT Required  |
| PATCH  | `/api/users/me/settings`       | Update user settings       | JWT Required  |
| POST   | `/api/users/me/settings/reset` | Reset settings to defaults | JWT Required  |

## 🏗️ Technical Implementation

### New Modules

- **UserSettings Model**: Stores all user preference data with sensible defaults
- **UpdateSettingsDto**: Validates partial updates with enum and range checks
- **UserSettingsDto**: Complete settings response with metadata

## 📝 Business Rules

### Settings Management

- ✅ Settings auto-created with defaults on first access
- ✅ Partial updates supported - only specified fields modified
- ✅ All settings have sensible defaults
- ✅ Settings are user-specific and private
- ✅ Reset option restores all defaults

### Validation

- ✅ Enum validation for theme, language, frequency options
- ✅ Range validation: itemsPerPage (6-48), sessionTimeout (5-1440 minutes)
- ✅ Boolean validation for all toggles
- ✅ Privacy-first defaults (email display off, marketing emails off)
