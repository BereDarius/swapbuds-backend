# v0.14.0 - User Settings & Preferences ⚙️

**Release Date**: November 22, 2024
**Test Coverage**: 475 passing tests

## 🎯 Overview

This release introduces a comprehensive user settings system that gives users complete control over their SwapBuds experience. With over 30 configurable options across 8 categories, users can now personalize everything from their profile visibility to accessibility preferences.

## ✨ New Features

### Comprehensive Settings System

#### **Profile Settings**

- ✅ **Display Email**: Control whether email is shown on public profile
- ✅ **Display Location**: Toggle location visibility on profile
- ✅ **Allow Messages**: Enable/disable messages from other users

#### **Privacy Settings**

- ✅ **Profile Visibility**: Choose between PUBLIC, FRIENDS_ONLY, or PRIVATE
- ✅ **Show Trade History**: Control visibility of completed trades
- ✅ **Show Reviews**: Toggle review visibility on profile
- ✅ **Show Statistics**: Control display of trade statistics

#### **Trade Settings**

- ✅ **Auto-Decline Expired Trades**: Automatically decline when trades expire
- ✅ **Allow Counter-Offers**: Enable/disable counter-offer functionality
- ✅ **Require Trade Message**: Force users to include messages with trade proposals

#### **Notification Frequency**

- ✅ **Email Digest**: Choose between REALTIME, DAILY, WEEKLY, or NEVER
- ✅ **Push Digest**: Configure REALTIME, HOURLY, DAILY, or NEVER

#### **UI Preferences**

- ✅ **Theme**: Light, Dark, or Auto mode
- ✅ **Language**: Support for EN, ES, FR, DE, PT
- ✅ **Items Per Page**: Customize pagination (6-48 items)
- ✅ **Default Sort**: Choose RECENT, POPULAR, PRICE_LOW, or PRICE_HIGH
- ✅ **Compact View**: Toggle between card and list view

#### **Search & Discovery**

- ✅ **Save Search History**: Keep history for quick access
- ✅ **Show Similar Items**: Enable recommendations
- ✅ **Enable Recommendations**: Personalized suggestions

#### **Accessibility**

- ✅ **High Contrast**: Enhanced visibility mode
- ✅ **Large Text**: Increased font sizes
- ✅ **Reduce Motion**: Minimize animations
- ✅ **Screen Reader Mode**: Optimized for screen readers

#### **Marketing & Communication**

- ✅ **Marketing Emails**: Opt-in for promotional content
- ✅ **Product Updates**: Feature announcements and updates
- ✅ **Community Newsletter**: Community highlights and news

#### **Advanced Settings**

- ✅ **Two-Factor Authentication**: Enhanced security
- ✅ **Session Timeout**: Configurable inactivity timeout (5-1440 minutes)

## 📊 Technical Details

### Database Schema

```prisma
enum Theme {
  LIGHT
  DARK
  AUTO
}

enum Language {
  EN // English
  ES // Spanish
  FR // French
  DE // German
  PT // Portuguese
}

model UserSettings {
  id     String @id @default(cuid())
  userId String @unique
  user   User   @relation(fields: [userId], references: [id])

  // Profile Settings
  displayEmail    Boolean @default(false)
  displayLocation Boolean @default(true)
  allowMessages   Boolean @default(true)

  // Privacy Settings
  profileVisibility String  @default("PUBLIC")
  showTradeHistory  Boolean @default(true)
  showReviews       Boolean @default(true)
  showStatistics    Boolean @default(true)

  // Trade Settings
  autoDeclineExpiredTrades Boolean @default(true)
  allowCounterOffers       Boolean @default(true)
  requireTradeMessage      Boolean @default(false)

  // Notification Frequency
  emailDigestFrequency String @default("DAILY")
  pushDigestFrequency  String @default("REALTIME")

  // UI Preferences
  theme         Theme    @default(AUTO)
  language      Language @default(EN)
  itemsPerPage  Int      @default(12)
  defaultSortBy String   @default("RECENT")
  compactView   Boolean  @default(false)

  // Search & Discovery
  saveSearchHistory     Boolean @default(true)
  showSimilarItems      Boolean @default(true)
  enableRecommendations Boolean @default(true)

  // Accessibility
  highContrast     Boolean @default(false)
  largeText        Boolean @default(false)
  reduceMotion     Boolean @default(false)
  screenReaderMode Boolean @default(false)

  // Marketing & Communication
  marketingEmails     Boolean @default(false)
  productUpdates      Boolean @default(true)
  communityNewsletter Boolean @default(false)

  // Advanced
  twoFactorEnabled Boolean @default(false)
  sessionTimeout   Int     @default(30)

  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt
}
```

#### Update User Settings

```http
PATCH /api/users/me/settings
Authorization: Bearer <token>
Content-Type: application/json

{
  "theme": "DARK",
  "language": "ES",
  "itemsPerPage": 24,
  "emailDigestFrequency": "WEEKLY",
  "highContrast": true
}
```

**Response**: Updated settings object

#### Reset Settings to Defaults

```http
POST /api/users/me/settings/reset
Authorization: Bearer <token>
```

**Response**: Reset settings with all default values

### DTOs

#### UpdateSettingsDto

- All fields optional - partial updates supported
- Full validation for each field
- Enum validation for theme, language, frequency options
- Range validation for numeric fields (itemsPerPage: 6-48, sessionTimeout: 5-1440)

#### UserSettingsDto

- Complete settings response
- Includes metadata (id, userId, timestamps)
- Swagger documentation for all fields

