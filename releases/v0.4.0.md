## 🎉 Release v0.4.0 - User Profile Management

This release adds comprehensive user profile management functionality, allowing users to view and update their profiles, including avatar uploads.

### ✨ New Features

- **User Profile Viewing** - Public profile access for all users
  - View any user's profile without authentication
  - Includes username, avatar, bio, location
  - Shows reputation score
  - Displays user statistics (items count, completed trades count)

- **Profile Update** - Edit your own profile information
  - Update bio (max 500 characters)
  - Update location (max 100 characters)
  - Update avatar URL
  - All fields optional for partial updates

- **Avatar Upload** - Upload profile pictures with Cloudinary
  - Direct avatar upload endpoint
  - Accepts JPEG, PNG, WebP formats
  - Maximum file size: 2MB
  - Automatic old avatar deletion
  - Stored in Cloudinary `swapbuds/avatars` folder
  - File type and size validation

### 📊 New API Endpoints

- `GET /api/users/:id` - View user profile (public)
  - No authentication required
  - Returns public profile information
  - Includes user statistics

- `PATCH /api/users/profile` - Update own profile (authenticated)
  - Requires JWT Bearer token
  - Update bio, location, avatarUrl
  - Returns updated profile

- `POST /api/users/avatar` - Upload avatar (authenticated)
  - Requires JWT Bearer token
  - Accepts: multipart/form-data with 'file' field
  - Returns profile with new avatar URL

### 🔧 Technical Details

- **User Statistics** - Automatic calculation via Prisma aggregations
  - Total items posted
  - Completed trades count

- **Avatar Management** - Smart cleanup
  - Automatic deletion of old avatars from Cloudinary
  - Prevents storage bloat

- **Validation** - Comprehensive input validation
  - File type checking (JPEG, PNG, WebP only)
  - File size limits (2MB for avatars)
  - DTO validation with class-validator

### 📦 Dependencies

No new dependencies - uses existing Cloudinary and Multer integration from v0.3.0
