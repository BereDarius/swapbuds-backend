# Release v0.4.0 - User Profile Management

**Release Date:** October 2024
**Version:** 0.4.0
**Type:** Feature Release

## 🎯 Overview

This release adds comprehensive user profile management functionality, allowing users to view and update their profiles, including avatar uploads with Cloudinary integration.

## ✨ New Features

### User Profile Viewing

- **Public Profile Access**: View any user's profile without authentication
- **Profile Information**: Username, avatar, bio, location, reputation score
- **User Statistics**: Items posted count and completed trades count
- **Automatic Aggregation**: Statistics calculated via Prisma

### Profile Update

- **Edit Profile**: Update your own profile information
- **Flexible Updates**: All fields optional for partial updates
- **Bio**: Max 500 characters
- **Location**: Max 100 characters
- **Avatar URL**: Direct URL updates supported

### Avatar Upload

- **Direct Upload**: Upload profile pictures to Cloudinary
- **File Validation**: JPEG, PNG, WebP formats only
- **Size Limit**: Maximum 2MB per avatar
- **Smart Cleanup**: Automatic deletion of old avatars
- **Organization**: Stored in `swapbuds/avatars` folder

## 🔌 API Endpoints

Three new REST endpoints for user profile management:

| Method | Endpoint             | Description           | Authorization      |
| ------ | -------------------- | --------------------- | ------------------ |
| GET    | `/api/users/:id`     | View user profile     | Public             |
| PATCH  | `/api/users/profile` | Update own profile    | Authenticated user |
| POST   | `/api/users/avatar`  | Upload profile avatar | Authenticated user |

## 🏗️ Technical Implementation

### Updated Modules

- **UsersService**: Added profile management methods
- **UsersController**: New endpoints for profile operations
- **DTOs**: UpdateProfileDto for validation

### Features

- **User Statistics**: Prisma aggregations for counting items and trades
- **Avatar Management**: Automatic cleanup of old Cloudinary avatars
- **Validation**: File type, size, and DTO validation

### Dependencies

No new dependencies - uses existing Cloudinary and Multer from v0.3.0

## 📝 Business Rules

### Profile Viewing

- ✅ Public access (no authentication required)
- ✅ Returns username, avatar, bio, location, reputation
- ✅ Includes user statistics (items count, completed trades)

### Profile Updates

- ✅ Only authenticated users can update their own profile
- ✅ All fields optional (bio, location, avatarUrl)
- ✅ Bio max length: 500 characters
- ✅ Location max length: 100 characters

### Avatar Upload

- ✅ Authenticated users only
- ✅ Accepted formats: JPEG, PNG, WebP
- ✅ Maximum file size: 2MB
- ✅ Old avatars automatically deleted from Cloudinary
- ✅ Returns updated profile with new avatar URL

## 🔄 Migration Notes

No database migrations required. User model supports profile fields from initial schema.
