# Release v0.10.3 - User Filtering and Search

**Release Date:** November 22, 2025
**Type:** Patch Release

## Overview

This patch release adds comprehensive filtering and search functionality for users, completing the filtering trifecta (trades, items, users). Users can now be filtered by location, reputation score, and searched by username or bio with full pagination and sorting support.

## ✨ Features

### User Filtering and Search

- **Filter by location** - Case-insensitive location search
- **Filter by reputation score range** - Find users within specific reputation ranges (0-5)
- **Search functionality** - Search by username or bio (case-insensitive)
- **Pagination** - Page and limit parameters for result pagination
- **Sorting** - Sort by createdAt, reputationScore, or username (ascending/descending)
- **Public endpoint** - Available at `GET /api/users` without authentication

### API Endpoint

```typescript
GET /api/users?location=San Francisco&minReputation=4&maxReputation=5
GET /api/users?search=collector&sortBy=reputationScore&sortOrder=desc
GET /api/users?page=1&limit=10
```

**Query Parameters:**

- `location` (string, optional) - Filter by user location
- `minReputation` (number, optional) - Minimum reputation score (0-5)
- `maxReputation` (number, optional) - Maximum reputation score (0-5)
- `search` (string, optional) - Search in username or bio
- `page` (number, optional, default: 1) - Page number
- `limit` (number, optional, default: 20) - Results per page
- `sortBy` (string, optional) - Sort field: `createdAt`, `reputationScore`, or `username`
- `sortOrder` (string, optional) - Sort direction: `asc` or `desc`

**Response Format:**

```json
{
  "users": [
    {
      "id": "user-123",
      "username": "collector123",
      "avatarUrl": "https://...",
      "bio": "Avid collector",
      "location": "San Francisco, CA",
      "reputationScore": 4.8,
      "createdAt": "2024-01-15T10:30:00Z",
      "itemsCount": 12,
      "tradesCount": 8
    }
  ],
  "total": 45,
  "page": 1,
  "limit": 20,
  "totalPages": 3
}
```


### For Frontend Developers

**New Endpoint Available:**

```typescript
// Fetch users with filters
const response = await fetch(
  '/api/users?location=San Francisco&minReputation=4',
);
const data = await response.json();

// data.users - array of user profiles
// data.total - total matching users
// data.page - current page
// data.limit - results per page
// data.totalPages - total pages available
```

**Filter Examples:**

```typescript
// Find users in a specific location
GET /api/users?location=New York

// Find highly-rated users
GET /api/users?minReputation=4.5&sortBy=reputationScore&sortOrder=desc

// Search for users by username or bio
GET /api/users?search=vintage collector

// Combine filters
GET /api/users?location=California&minReputation=3&search=games&page=1&limit=10
```
