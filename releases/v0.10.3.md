# Release v0.10.3 - User Filtering and Search

**Release Date**: November 22, 2025
**Version**: 0.10.3
**Release Type**: Patch Release

## Overview

Comprehensive user filtering and search functionality completing the filtering trifecta (trades, items, users). Filter by location and reputation score, search by username or bio, with full pagination and sorting.

## Features

### User Filtering and Search
- **Location Filter**: Case-insensitive location search
- **Reputation Range**: Filter by min/max reputation score (0-5)
- **Search**: Search username or bio (case-insensitive)
- **Pagination**: Page and limit parameters
- **Sorting**: Sort by createdAt, reputationScore, or username (asc/desc)
- **Public Endpoint**: Available without authentication

### Query Capabilities
- Find users in specific locations
- Find highly-rated trading partners
- Search by interests (bio) or username
- Combine multiple filters
- Sort by various criteria

## API Endpoints

| Method | Endpoint | Description |
| ------ | -------- | ----------- |
| GET    | `/api/users` | Get filtered users list (public) |

### Query Parameters
- `location` (string) - Filter by user location
- `minReputation` (number) - Minimum reputation (0-5)
- `maxReputation` (number) - Maximum reputation (0-5)
- `search` (string) - Search username or bio
- `page` (number, default: 1) - Page number
- `limit` (number, default: 20) - Results per page
- `sortBy` (string) - Field: createdAt, reputationScore, username
- `sortOrder` (string) - Direction: asc or desc

### Example Requests
```
GET /api/users?location=San Francisco&minReputation=4
GET /api/users?search=collector&sortBy=reputationScore&sortOrder=desc
GET /api/users?location=California&minReputation=3&page=1&limit=10
```

### Response Format
```json
{
  "users": [
    {
      "id": "user-123",
      "username": "collector123",
      "avatarUrl": "https://...",
      "bio": "Avid collector",
      "location": "San Francisco, CA",
      "reputationScore": 4.8,
      "createdAt": "2024-01-15T10:30:00Z",
      "itemsCount": 12,
      "tradesCount": 8
    }
  ],
  "total": 45,
  "page": 1,
  "limit": 20,
  "totalPages": 3
}
```

## Technical Implementation

### New Files

- **UsersService.findAllFiltered()**: Dynamic filtering logic

  - Pagination and sorting
  - Returns metadata with results

### Controller
- **UsersController.findAll()**: Public endpoint
  - No authentication required
  - Comprehensive Swagger docs
  - Query parameter decorators
