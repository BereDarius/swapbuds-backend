# Release v0.10.1 - Reviews and Trade Filtering

**Release Date**: November 22, 2025
**Version**: 0.10.1
**Release Type**: Patch Release

## Overview

Comprehensive reviews/ratings system allowing users to leave feedback after completed trades, plus advanced trade filtering capabilities with status, date range, category, and search parameters.

## Features

### Reviews and Ratings System
- **User Reviews**: Review trading partners after completed trades
- **Rating System**: 1-5 star rating with optional comments
- **Reputation Calculation**: Automatic reputation score updates
- **Review Management**: Full CRUD operations (create, read, update, delete)
- **Authorization**: Only trade participants can review, one review per trade per user
- **Automatic Updates**: Reputation recalculated on review changes

### Trade Filtering and Search
- **Status Filtering**: Filter by PENDING, ACCEPTED, REJECTED, CANCELLED
- **Date Range**: Filter between specific dates
- **Category Filter**: Filter by item category
- **Search**: Case-insensitive item title search
- **Pagination**: Page and limit parameters
- **Smart Routing**: Optimized query when no filters applied
- **Pagination Metadata**: Total count, page, limit, totalPages

## API Endpoints

### Reviews Module

| Method | Endpoint | Description |
| ------ | -------- | ----------- |
| POST   | `/api/reviews/trades/:tradeId` | Create review |
| GET    | `/api/reviews/users/:userId` | Get user's received reviews |
| GET    | `/api/reviews/me` | Get own received reviews |
| GET    | `/api/reviews/me/given` | Get reviews given |
| GET    | `/api/reviews/:id` | Get specific review |
| PUT    | `/api/reviews/:id` | Update review |
| DELETE | `/api/reviews/:id` | Delete review |
| GET    | `/api/reviews/trades/:tradeId/all` | Get all reviews for trade |

### Trades Filtering

Enhanced GET `/api/trades/my-trades` with query parameters:
- `status` - Trade status enum
- `startDate` - ISO date string
- `endDate` - ISO date string
- `category` - Item category
- `search` - Item title search
- `page` - Page number (default: 1)
- `limit` - Items per page (default: 20)

## Technical Implementation

### Database Schema
```prisma
model Review {
  id        String   @id @default(cuid())
  rating    Int      // 1-5 stars
  comment   String?
  authorId  String
  targetId  String
  tradeId   String
  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt
  
  @@unique([authorId, tradeId])
  @@index([targetId])
  @@index([authorId])
}
```

### Services
- **ReviewsService**: Full CRUD with reputation calculation
  - Uses `@Cacheable` and `@CacheInvalidate` decorators
  - Cache TTL: 2 minutes
  - Validates trade completion status
  - Only authors can modify their reviews

- **TradesService**: Enhanced filtering logic
  - Dynamic query building based on filters
  - Pagination with metadata
  - Smart routing for performance

### Response Format
```json
{
  "trades": [...],
  "total": 42,
  "page": 1,
  "limit": 20,
  "totalPages": 3
}
```
