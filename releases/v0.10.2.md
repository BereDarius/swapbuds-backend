# Release v0.10.2 - Schema Validation & ItemCategory Enum

**Release Date:** November 22, 2025
**Type:** Patch Release

## Overview

This patch release fixes critical schema mismatches between DTOs and the Prisma schema, ensuring proper type safety and data integrity. The primary focus is removing incorrect fields (price, location on items) and implementing a proper ItemCategory enum for better data validation.

## 🐛 Bug Fixes

### Schema Validation Issues

- **Removed price fields from items** - This is a swap-only platform, not a buying/selling platform
  - Removed `minPrice` and `maxPrice` from `ItemFilterDto`
  - Removed price filtering logic from items service
  - Removed price-related API query parameters
  - Removed price-related tests

- **Removed location field from items** - Location belongs to User, not Item
  - Removed `location` from `ItemFilterDto`
  - Removed location filtering logic from items service
  - Removed location API query parameter

- **Fixed ItemCondition enum mismatch**
  - Schema has: `NEW`, `LIKE_NEW`, `EXCELLENT`, `GOOD`, `FAIR`, `POOR`
  - Now importing `ItemCondition` from `@prisma/client` instead of custom enum
  - Updated all Swagger documentation to include `EXCELLENT`

## ✨ Enhancements

### ItemCategory Enum

- **Created ItemCategory enum in Prisma schema**
  ```prisma
  enum ItemCategory {
    ELECTRONICS
    CLOTHING
    BOOKS
    TOYS
    SPORTS
    COLLECTIBLES
    HOME
    OTHER
  }
  ```
- Changed `Item.category` from `String` to `ItemCategory` enum
- Safe database migration preserves existing data
- Type-safe category validation throughout the application

### Updated DTOs

- `CreateItemDto` - Now uses `ItemCategory` enum with proper validation
- `ItemResponseDto` - Returns `ItemCategory` enum
- `ItemFilterDto` - Filters by `ItemCategory` enum
- All test fixtures updated to use proper enums

### API Documentation

- Updated Swagger documentation with all category enum values
- Fixed status enum values: `AVAILABLE`, `IN_TRADE`, `TRADED`, `REMOVED`
- Added missing `EXCELLENT` condition to API docs

## 🔄 Migration Guide

### For Backend Developers

**No breaking changes** - The migration is backward compatible for existing data.

If you have local development data:

```bash
# Pull latest changes
git pull origin main

# Run migration
yarn prisma migrate dev

# Regenerate Prisma client (if needed)
yarn prisma generate
```

### For Frontend Developers

**Breaking Change:** Item category is now an enum, not a free-text string.

Before:

```typescript
category: 'Electronics'; // Any string
```

After:

```typescript
category: 'ELECTRONICS'; // Must be one of the enum values
// Valid values: ELECTRONICS, CLOTHING, BOOKS, TOYS, SPORTS, COLLECTIBLES, HOME, OTHER
```

**Removed Fields:**

- Items no longer have `price`, `minPrice`, or `maxPrice` fields
- Items no longer have `location` field (use `user.location` instead)

**Updated Filter Parameters:**

```typescript
// GET /api/items?category=ELECTRONICS&condition=EXCELLENT
// Valid categories: ELECTRONICS | CLOTHING | BOOKS | TOYS | SPORTS | COLLECTIBLES | HOME | OTHER
// Valid conditions: NEW | LIKE_NEW | EXCELLENT | GOOD | FAIR | POOR
// Valid statuses: AVAILABLE | IN_TRADE | TRADED | REMOVED
```
