# Release v0.11.2 - Trade Statistics

**Release Date:** November 22, 2024
**Type:** Patch Release (Enhancement)

## 🎯 Overview

This patch release introduces comprehensive trade statistics for users, providing insights into their trading activity, success rates, and response times. The new statistics endpoint allows users to evaluate trading partners and build trust within the SwapBuds community.

## ✨ New Features

### User Trade Statistics

#### Statistics Provided

- **Total Trades Initiated:** Number of trade proposals created by the user
- **Total Trades Received:** Number of trade proposals received by the user
- **Total Completed Trades:** Successful trades that reached completion
- **Total Accepted Trades:** Trades that were accepted (may still be in progress)
- **Total Rejected Trades:** Trades that were declined
- **Total Cancelled Trades:** Trades that were cancelled by either party
- **Total Expired Trades:** Trades that expired without response
- **Success Rate:** Percentage of completed trades relative to total trades `(completed / (initiated + received)) * 100`
- **Average Response Time:** Average time in hours to respond to trade proposals
- **Total Counter-Offers:** Number of counter-offers made by the user
- **Pending as Proposer:** Currently pending trades where user is the proposer
- **Pending as Responder:** Currently pending trades where user is the responder

#### Public Endpoint

Statistics are publicly accessible to help users evaluate potential trading partners:

```
GET /api/users/:id/statistics
```

**Response Example:**

```json
{
  "totalTradesInitiated": 10,
  "totalTradesReceived": 15,
  "totalCompletedTrades": 8,
  "totalAcceptedTrades": 10,
  "totalRejectedTrades": 5,
  "totalCancelledTrades": 2,
  "totalExpiredTrades": 3,
  "successRate": 32.0,
  "averageResponseTime": 18.5,
  "totalCounterOffers": 4,
  "pendingAsProposer": 2,
  "pendingAsResponder": 3
}
```

#### Performance Optimization

- **Caching:** Statistics are cached for 5 minutes (300 seconds) to reduce database load
- **Parallel Queries:** All trade counts are fetched in parallel using `Promise.all`
- **Efficient Calculations:** Response time calculated from existing timestamps

## 🏗️ Technical Implementation

### New DTO

**UserStatisticsDto** (`src/users/dto/user-statistics.dto.ts`)

```typescript
export class UserStatisticsDto {
  totalTradesInitiated: number;
  totalTradesReceived: number;
  totalCompletedTrades: number;
  totalAcceptedTrades: number;
  totalRejectedTrades: number;
  totalCancelledTrades: number;
  totalExpiredTrades: number;
  successRate: number;
  averageResponseTime: number | null;
  totalCounterOffers: number;
  pendingAsProposer: number;
  pendingAsResponder: number;
}
```

### Service Method

**UsersService.getUserStatistics(userId: string)**

- Validates user exists
- Executes 10 parallel count queries using `Promise.all`
- Calculates success rate percentage
- Calculates average response time from `createdAt` → `updatedAt` delta
- Returns null for `averageResponseTime` if no trades have been responded to
- Implements `@Cacheable` decorator with 300-second TTL

### Controller Endpoint

**UsersController** (`src/users/users.controller.ts`)

- Added `getUserStatistics(@Param('id') userId: string)` endpoint
- Marked as `@Public()` for unrestricted access
- Includes comprehensive Swagger documentation
- Returns `UserStatisticsDto`

## 📊 Statistics Calculations

### Success Rate

```typescript
successRate = totalTrades > 0 ? (completedTrades / totalTrades) * 100 : 0;
```

Where `totalTrades = tradesInitiated + tradesReceived`

### Average Response Time

```typescript
// For each responded trade (ACCEPTED or REJECTED)
responseTime = updatedAt - createdAt

// Average in hours
averageResponseTime = (sum of all responseTimes) / numberOfRespondedTrades / (1000 * 60 * 60)
```

Returns `null` if user has never responded to any trades.

### Counter-Offers Count

```typescript
// Trades where user is responder and has counter-offers
totalCounterOffers = count(responderId = userId AND counterOffers.length > 0)
```

```typescript
// Fetch user statistics
const response = await fetch(`/api/users/${userId}/statistics`);
const stats = await response.json();

// Display on user profile
<div>
  <h3>Trading Statistics</h3>
  <p>Success Rate: {stats.successRate.toFixed(1)}%</p>

  <p>Completed: {stats.totalCompletedTrades}</p>
  {stats.averageResponseTime && (
    <p>Avg Response: {stats.averageResponseTime.toFixed(1)} hours</p>
  )}
</div>
```
